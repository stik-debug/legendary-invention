Install ChamaPay

Add ChamaPay to your phone or computer for quick access. No Google Play Store or app-store payment is needed.

✓ Opens from your home screen✓ No app-store download required✓ Updates when you visit online
📱

Android phone

  1. Open this website in Chrome.
  2. Tap the browser menu ⋮.
  3. Choose Install app or Add to Home screen.
  4. Confirm. Look for ChamaPay on your home screen.
🍎

iPhone or iPad

  1. Open this website in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.
💻

Computer

  1. Open ChamaPay in Chrome or Edge.
  2. Look for the install icon in the address bar, or open the browser menu.
  3. Choose Install ChamaPay and confirm.

Can't see an install option?

Make sure you are online and using a supported browser. On some phones, use the browser's Add to Home screen option. If your browser does not support installation, you can still save this website as a home-screen shortcut.
